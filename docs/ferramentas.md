# Ferramentas

Consulta Veicular Nacional expõe 1 ferramenta (todas somente leitura).

### 1. `veiculo_nacional_consultar`
**Input**: `Placa`, `completo` (opcional)

Dados cadastrais de um veículo a partir da placa em base nacional: marca, modelo, ano de fabricação, cor e demais características.

## Prompts de exemplo

```
Quais os dados do veículo de placa ABC1D23?
Marca, modelo e ano da placa ABC1D23
```
